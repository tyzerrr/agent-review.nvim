1. INTRODUCTION                                           *agent-review-intro*

agent-review.nvim opens a review tab with two windows:

  left   the file at a base revision (default HEAD), read-only, in a
         `nofile` scratch buffer, so no LSP client attaches
  right  the real working-tree buffer, where LSP, edits and saves work

When the right window shows another file (|gd|, |CTRL-O|, |:edit|,
|:cnext|, a Telescope pick, ...), the left window switches to that file at
the base revision and both are diffed again. Files outside the repository
and gitignored files turn the diff off; new files get an empty base.

Requires Neovim 0.12+ and git.

==============================================================================
2. SETUP                                                  *agent-review-setup*

>lua
  require("agent-review").setup({})
<
Commands and |<Plug>| mappings work without setup(). The global keymaps
are created by setup().

==============================================================================
3. COMMANDS                                            *agent-review-commands*

:AgentReview [rev]                                              *:AgentReview*
    Open a review of the working tree against [rev] (default: config.base).
    When the revision names a ref such as HEAD and the ref moves (commit,
    reset, checkout), the base moves with it, so committed changes drop out.
    A commit hash stays put. See `auto_refresh.follow_base`.

:AgentReviewToggle [rev]                                  *:AgentReviewToggle*
    Toggle the review.

:AgentReviewClose                                          *:AgentReviewClose*
    Close the review tab.

:AgentReviewFiles                                          *:AgentReviewFiles*
    Pick a changed file (Telescope if available, otherwise |vim.ui.select()|).

:AgentReviewHunks                                          *:AgentReviewHunks*
    Pick a changed hunk.

:AgentReviewPR [preset|number]                                *:AgentReviewPR*
    List GitHub pull requests of the repository (via the `pr.remote` remote
    and the gh CLI). Without an argument, `pr.lists` is used; with a name,
    the preset of that name from `pr.presets`. With a number (`123` or
    `#123`), or when a PR is picked, the PR opens in the review layout.
    See |agent-review-pr|.

:AgentReviewPRClean                                       *:AgentReviewPRClean*
    Remove the checked-out pull requests that are not being reviewed.

:AgentReviewQuickfix [files|hunks]                      *:AgentReviewQuickfix*
    Rebuild the quickfix list with one entry per file or per hunk, and open
    it.

:AgentReviewRefresh                                      *:AgentReviewRefresh*
    Reload the changed files and buffers. Usually not needed: see
    |agent-review-auto-refresh|.

4. KEYMAPS                                              *agent-review-keymaps*

Defaults:

  global  <leader>dr  toggle          <leader>dR  open_rev
          <leader>dl  files           <leader>dh  hunks
          <leader>dp  pr_list
  review  ]f          next_file       [f          prev_file
          ]q          qf_next         [q          qf_prev
          <leader>dv  toggle_viewed
  base    q           close           <C-l> (x)   send_to_claude
  quickfix <CR>      qf_open         <Tab>       toggle_viewed

"review" keys are buffer-local on both review windows; "base" keys only on
the base window; "quickfix" keys only on the quickfix window in the review
tab, which also gets the "review" keys. Outside the review tab, or on a
quickfix list agent-review didn't create, the keys fall back to your global
mapping (e.g. flash.nvim on <CR>) or the built-in command. Every value is
a key, a list of keys, or `false`. `keymaps = false` disables all of them.
An unknown action name with a value of the form
`{ key, function(session) end, desc = "", mode = "n" }` adds a custom action.

Actions and their <Plug> mappings:

  toggle           <Plug>(agent-review-toggle)
  open             <Plug>(agent-review-open)
  open_rev         (types ":AgentReview " on the command line)
  close            <Plug>(agent-review-close)
  files            <Plug>(agent-review-files)
  hunks            <Plug>(agent-review-hunks)
  pr_list          <Plug>(agent-review-pr-list)
  next_file        <Plug>(agent-review-next-file)
  prev_file        <Plug>(agent-review-prev-file)
  qf_next          <Plug>(agent-review-qf-next)
  qf_prev          <Plug>(agent-review-qf-prev)
  qf_open          <Plug>(agent-review-qf-open)
  toggle_viewed    <Plug>(agent-review-toggle-viewed)
  refresh          <Plug>(agent-review-refresh)
  quickfix_files   <Plug>(agent-review-quickfix-files)
  quickfix_hunks   <Plug>(agent-review-quickfix-hunks)
  send_to_claude   <Plug>(agent-review-send-to-claude)    (visual)

5. CONFIGURATION                                         *agent-review-config*

>lua
  require("agent-review").setup({
    base = "HEAD",
    diffopt = { "internal", "filler", "closeoff", "inline:char",
                "linematch:60", "algorithm:histogram", "indent-heuristic" },
    fold_unchanged = false,
    fillchar = "╱",
    winbar = true,
    picker = "auto",            -- "auto" | "telescope" | "ui_select"
    quickfix = { auto = true, open = true, height = 8, mode = "files" },
    tests = { hide = false, patterns = nil, extra_patterns = {} },
    auto_refresh = { enabled = true, debounce = 200,    -- or false
                     follow_base = true },
    keymaps = {
      global = { toggle = "<leader>dr", open_rev = "<leader>dR",
                 files = "<leader>dl", hunks = "<leader>dh" },
      review = { next_file = "]f", prev_file = "[f",
                 qf_next = "]q", qf_prev = "[q", toggle_viewed = "<leader>dv" },
      base = { close = "q", send_to_claude = "<C-l>" },
      quickfix = { qf_open = "<CR>", toggle_viewed = "<Tab>" },
    },
    claude = { focus_after_send = true, terminal_pattern = "claude",
               follow_terminal = true },
    highlights = {},
  })
<
'diffopt' is applied only while a review is open and restored afterwards.

                                                   *agent-review-auto-refresh*
While a review is open, the repository is watched for file changes (`.git/`
is ignored), and the review refreshes `auto_refresh.debounce` ms after the
last write: the file list and quickfix are rebuilt, changed buffers are
reloaded with |:checktime| and the diff is updated. |FocusGained| and
|TermLeave| also refresh, which covers Linux, where only the top-level
directory can be watched. Buffers with unsaved edits are never overwritten
silently (|W12|).

Changes inside `.git/` don't trigger a refresh by themselves, but they make
agent-review check whether the base ref moved. When it did (for example
after a commit) and `follow_base` is true, the base moves to the new commit
and the committed files drop out of the review. In a `git worktree`, the
shared git directory (outside the working directory) is watched as well.
When the file shown in the review drops out of the list, both windows move
to the entry quickfix selects next. When nothing is left, both windows are
cleared until the next change shows up. Files that were never in the list (an
LSP jump, for example) stay on screen.

6. PICKERS AND QUICKFIX                                 *agent-review-pickers*

When a review opens, the changed files are put into a quickfix list titled
"Agent Review: <base>" and its window opens at the bottom of the review tab.
Files opened from the base window are moved to the working window.
<CR> in that quickfix window opens the entry in the working window.
In the review windows and the quickfix window, `]q` and `[q` wrap around at
the ends of the list and accept a count. Refreshing keeps the current entry
selected.

                                                             *agent-review-pr*
A pull request opens like a local review: its code on the right (with LSP),
the merge-base with the target branch on the left, the changed files in
quickfix. The code is checked out under
`<state>/github.com/owner/repo/<number>` from a private copy of the
repository (`repo.git`), so nothing is written to your repository. The diff
is computed locally from fetched commits; only the PR's metadata comes from
the API (with an ETag). |:AgentReviewRefresh| picks up new pushes.

Pull request lists are written with plain keys instead of GitHub's search
syntax. Each entry of `pr.lists` is one search; the results are merged:
>lua
  pr = {
    lists = { { author = "@me" }, { reviewer = "@me" } },  -- default
    state = "open",          -- "open" | "closed" | "merged" | "all"
    presets = {
      team = { { reviewer = "@me", draft = false, base = "main" } },
      urgent = "is:open label:urgent",   -- raw GitHub query
    },
  }
<
Keys: author, reviewer (includes team requests), assignee, involves,
mentions, label (string or list), base, head, draft, state. All searches are
sent in one GraphQL request; the result is cached for `pr.list_ttl` seconds
and shown immediately after that while a fresh list is fetched.

                                                         *agent-review-viewed*
Mark files as reviewed with <Tab> in the quickfix window (the line under the
cursor) or <leader>dv in the diff windows. Marked files show a "✓" in
quickfix, the title shows "(3/8 viewed)" and the winbar "✓ viewed". The mark
remembers the file's content and goes away when the file changes again.
Marks are stored in `.git/agent-review/viewed.json`.

                                                          *agent-review-tests*
With `tests.hide = true`, test files are left out of quickfix, ]f/[f, the
pickers and the winbar count. Built-in patterns follow Go, JS/TS, Python, Lua
and Rust conventions (`*_test.go`, `*.test.ts`, `*.spec.tsx`, `__tests__/`,
`test_*.py`, `conftest.py`, `*_spec.lua`, `spec/`, `tests/`, ...).
`tests.patterns` replaces them and `tests.extra_patterns` adds to them; both
are Lua patterns matched against "/" .. (path relative to the root).

Telescope extension:
>vim
  :Telescope agent_review          " changed files
  :Telescope agent_review hunks    " every hunk
<
The preview shows the working-tree code with tree-sitter highlighting,
added lines in green and removed lines as red virtual lines.

==============================================================================
7. CLAUDE CODE                                           *agent-review-claude*

With claudecode.nvim, select lines in the base window and press <C-l>. The
base file is written to `.git/agent-review/base-<sha>/<path>` and sent as a
file mention with the line range. A visible Claude terminal is moved into the
review tab and restored to its original tab on close; one opened inside the
review tab moves to the tab you came from. Opening, closing or resizing it
re-balances the diff windows.

Other windows you opened in the review tab (help, other files, other
terminals) are reopened in the tab you return to when the review closes.

==============================================================================
8. LUA API AND EVENTS                                       *agent-review-api*

>lua
  local ar = require("agent-review")
  ar.setup(opts)
  ar.open(base, { path = "src/x.lua" })
  ar.open_at("src/x.lua", 42)
  ar.close()
  ar.toggle(base)
  ar.next_file()  ar.prev_file()
  ar.files()      ar.hunks()
  ar.quickfix("files" | "hunks")
  ar.qf_next()    ar.qf_prev()
  ar.toggle_viewed()
  ar.refresh()
<
                                    *AgentReviewOpen* *AgentReviewClose*
|User| autocommands fire when a review opens or closes, with `data` set to
`{ root, base, base_sha, tab, left_win, right_win }`.

9. HIGHLIGHTS                                        *agent-review-highlights*

  AgentReviewAdd          added/changed lines (working side)
  AgentReviewAddText      changed characters (working side)
  AgentReviewDelete       removed/changed lines (base side)
  AgentReviewDeleteText   changed characters (base side)
  AgentReviewFiller       filler opposite one-sided lines
  AgentReviewWinbarBase   "BASE" label
  AgentReviewWinbarWork   "WORKING" label

By default they are derived from the |hl-Normal| background. Override them
with `highlights = { AgentReviewAdd = { bg = "#1f3a28" } }`.
